Ruang Terbuang di Atas

2×

KPI Duplikat

2 layer

Command Bar Terpadu

Gabungkan project context + pipeline tabs dalam satu compact header. Ini model yang dipakai Figma, Linear, dan Bloomberg Terminal.

~140px

Chrome Berkurang 220px

Command bar (44px) + tabs (40px) + budget strip (44px) = 128px total. Konten mendapat 220px lebih banyak ruang vertikal.

1 strip

Budget Strip Terpadu

Satu baris 44px menggantikan BudgetHealthPanel + SummaryStrip. Menampilkan 4 angka kritis: Budget / RAB% / Actual% / CPI.
