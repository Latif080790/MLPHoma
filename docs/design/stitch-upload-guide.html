# DESIGN.md — MLPHoma · NATA LABA Construction Suite ## Product Overview **MLPHoma** is a professional web-based construction project management platform (PWA) for the Indonesian construction industry. It helps project teams — project managers to field supervisors — manage the full construction lifecycle: cost planning, scheduling, finance, procurement, and handover. **Primary users:** Project Manager, Quantity Surveyor (QS), Site Manager, Finance Officer, Procurement Admin, QHSE Officer, Directors. **Business context:** All monetary values are in Indonesian Rupiah (IDR). Follows SNI standards for AHSP and TKDN regulations. --- ## Design Language **System name:** MERIDIAN v1.0 **Aesthetic:** Obsidian Precision × Indonesian Craft **Character:** Premium enterprise tool. Like Bloomberg Terminal designed for Indonesian infrastructure — dark, data-dense, trustworthy, with warm gold accents referencing Indonesian architectural heritage. **Primary theme:** Dark-first (obsidian surfaces + electric cobalt actions + warm gold for all financial data). Light mode: warm limestone parchment. **Signature rule:** Every Indonesian Rupiah value is ALWAYS in warm gold (#FBBF24 dark / #92400E light) using JetBrains Mono — never broken. --- ## Color Palette ### Dark Mode (primary) - bg-page: #060910 (obsidian black) - bg-surface: #0C1220 (deep navy) - bg-elevated: #131C2E (modals/drawers) - bg-overlay: #1A253C (dropdowns) - border: #192338 / #213047 - text-primary: #E2EAF5 (15.2:1 contrast AAA) - text-secondary:#7A90AB (6.1:1 AA+) - text-muted: #3D5068 - background has subtle blueprint grid: 80px major / 16px minor, very faint cobalt lines ### Light Mode (warm limestone) - bg-page: #F2EFE9 (warm limestone parchment, NOT pure white) - bg-surface: #FDFCF9 (warm white) - border: #CEC8BA - text: #1A1814 (warm near-black) / #50493E (secondary) - grid lines: warm sepia rgba(120,100,60,.05) ### Accent Colors (adaptive per mode) - Cobalt Blue (action/selection): dark #3B82F6/#60A5FA · light #2563EB/#1E40AF - Warm Gold (ALL IDR values — mandatory): dark #F59E0B/#FBBF24 · light #D97706/#92400E - Jade Green (success/positive KPI): dark #22C55E/#4ADE80 · light #16A34A/#14532D - Coral Red (danger/error/overdue): dark #F43F5E/#FB7185 · light #E11D48/#9F1239 - Amber Orange (warning/pending): dark #F97316/#FB923C · light #EA580C/#9A3412 - Violet (analytics/AI): dark #8B5CF6/#A78BFA · light #7C3AED/#5B21B6 - Teal (realtime/live): dark #14B8A6/#2DD4BF · light #0D9488/#134E4A --- ## Typography - Heading/Display: font "Bricolage Grotesque" — weights 700-800, letter-spacing -0.035em, variable opsz axis - Body/UI: font "Nunito Sans" — weights 400-700 - Data/Numbers/KPIs: font "JetBrains Mono" — ALL numeric values only, tabular figures ### Type Scale - 10px: table headers (uppercase, 0.12em tracking) - 12px: captions, badges - 14px: body small, sidebar - 16px: default body - 20-30px: section headings (Bricolage Grotesque) - 36-48px: KPI values (JetBrains Mono) ### Rules - ALL Rupiah: JetBrains Mono + gold color — NO EXCEPTIONS - Format: "Rp 12.800.000.000" (dot=thousands, no decimal for whole) - Percentage: "34,5%" (comma=decimal, Indonesian locale) --- ## Spacing (4px base) - 4px, 8px, 12px, 16px, 24px, 32px, 48px - Card padding: 20px · Table cell: 9px×12px · Page: 24px horizontal ## Border Radius - 2px (progress bars) · 4px (badges) · 6px (buttons/inputs) · 8px (dropdowns) - 12px (cards — most common) · 16px (drawers) · 9999px (pills/avatars) ## Elevation - Cards: shadow-xs (0 1px 2px rgba(0,0,0,.5)) - Hover/dropdown: shadow-md (0 4px 16px rgba(0,0,0,.5)) - Modal: shadow-lg (0 16px 40px rgba(0,0,0,.6)) - KPI card glow: 0 0 24px rgba(accent-color, 0.16) --- ## Layout Structure (every page) L1 — AppHeader (56px): Logo + brand name | Active project name + status badge | Search | Bell + Avatar L2 — GlobalContextBar (44px): Project code | Pipeline step | Status | "● LIVE" teal indicator | Day counter L3 — WorkspaceHeader: Title (Bricolage Grotesque 28px) | Subtitle (muted) | Action buttons right L4 — SummaryStrip: 5-6 horizontal KPI cards with 1px dividers L5 — AlertStrip: Conditional warning banner L6 — ContentArea: Main content (tree/table/chart/tabs) Navigation sidebar: 224px wide, collapsible to 60px. Groups: Overview | Cost Control | Schedule | Operations | Portfolio | System --- ## Components ### Cards - Background: surface color · Border: 1px · Radius: 12px - TOP ACCENT STRIP: 3px solid colored bar matching category (mandatory) - Hover: translateY(-2px) + enhanced shadow ### Status Pills (always full rounded) - 11px Nunito Sans 700 · Always includes 5px colored dot prefix "●" - ACTIVE/APPROVED/COMPLETED → jade · PENDING/IN PROGRESS → amber - OVERDUE/REJECTED → coral · PLANNING → cobalt · DRAFT → muted gray - LIVE/AUTO → teal · AI/ANALYTICS → violet ### KPI Cards (Command Center, 2×4 grid) - Large JetBrains Mono value + colored top border + trend indicator - Financial values: always gold · Positive KPI: jade · Warning: amber · Negative: coral - "LIVE" badge: teal with pulsing dot animation ### Data Tables - Headers: 10px uppercase, letter-spacing 0.12em, muted, sticky - Default row height: 38px · Alternating stripe: rgba(cobalt, 0.025) - Financial cells: right-aligned, JetBrains Mono, gold color - Density: compact 30px / default 38px / comfortable 50px ### WBS Tree - L1 codes: cobalt pill background · L2: muted gray pill · L3: no background - Children indented 20px per level + 1.5px border-left connector - Drag handle: hover only · Action buttons: hover only (right side) - Selected row: cobalt bg rgba(8%) + cobalt border ### WBS Badges (right side of each row) - Auto: teal (timeline auto-propagated) · Locked: amber (manual required) - Budget: gold (RAB linked amount) · QC Passed: jade · QC Pending: amber ### Buttons - Primary: cobalt bg · Ghost: transparent · Outline: transparent+border · Destructive: coral - All: Nunito Sans 700, 12px, 6px×12px padding, radius 7px --- ## Interaction Patterns ### Drag & Drop (WBS) - Dragging: 40% opacity + scale(1.02) + large shadow - Drop zone: 2px dashed cobalt border + cobalt bg 5% ### Inline Edit (table cells) - Hover: subtle bg + 1px border - Active: cobalt border 1.5px + glow - Small [✓] [✗] buttons appear below ### Delete Confirmation - Always an AlertDialog (never silent delete) - Shows: item name + child count + linked records to be unlinked - Amber warning box for cascade effects - [Batal] outline | [Hapus Semua] coral ### Empty States - Centered icon in colored box + Indonesian title + brief description + CTA button ### Toast Notifications - Jade ✓ success · Coral ✕ error · Amber ⚠ warning · Cobalt ℹ info - Position: bottom-right · Auto-dismiss: 4 seconds --- ## Real Data (use this — not lorem ipsum) Project: CMPLNG VILLAGE · Code: PRJ-2026-0019 · Status: ACTIVE Budget: Rp 12.800.000.000 · RAB: Rp 4.966.572.640 (39%) Actual Spent: Rp 1.847.293.150 (14,4%) · Sisa: Rp 10.952.706.850 CPI: 1.12 (jade — efficient) · SPI: 0.87 (amber — slight delay) Progress: 34,5% (vs target 38,2%) · Hari ke-45 dari 180 hari EAC: Rp 11.400.000.000 · VAC: +Rp 1.400.000.000 (under budget) Approval Pending: 7 (3 overdue, 4 dalam SLA) WBS Structure: 1 Pekerjaan Persiapan | Rp 450jt | 100% | QC PASSED 1.1 Mobilisasi | 100% | Auto | QC PASSED 1.2 Pembersihan Lahan | 100% | Auto | QC PASSED 2 Pekerjaan Sipil | Rp 3,8M | 58% | QC PENDING 2.1 Pondasi | 85% | Auto 2.1.1 Galian Tanah | 100% | QC PASSED 2.1.2 Pengecoran Beton K-300 | 70% | LOCKED 2.2 Struktur Atas | 32% | Auto | Rp 2,1M 3 MEP | Rp 716jt | 0% | QC PENDING --- ## Accessibility - WCAG AA minimum all text (4.5:1) · AAA for financial data (7:1) - Focus: 4px solid cobalt, 2px offset - All interactive: min 44px touch target - Full keyboard navigation: Tab, Enter, Escape, Arrow keys - aria-live regions for dynamic content ## Device Priority Desktop-first (1280-1440px): Command Center, Costing, Schedule, Finance, Supply Chain Mobile-first (375px): Field Tasks only Tablet (768px+): Documents, QHSE, Handover, Settings ## Brand Company: NATA LABA · Product: MLPHoma · Tagline: CONSTRUCTION SUITE Logo color: #F97316 (orange) — sidebar header only Stack: React 18 · TypeScript · Tailwind CSS · shadcn/ui · Supabase · PWA --- *DESIGN.md v1.0 — MERIDIAN System — Juni 2026*
