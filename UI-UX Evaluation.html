02
Dark Theme Harus Jadi Default
Light mode terasa generic. Dark mode sesuai konteks industri konstruksi.
● High
Mengapa dark mode lebih tepat untuk produk ini?
Aplikasi konstruksi sering digunakan di lapangan (cahaya terang, silau layar), ruang kontrol, dan di meja kerja malam hari. Dark mode mengurangi eye strain dalam penggunaan panjang, lebih cocok untuk dashboard data yang dense, dan memberikan kesan profesional enterprise yang sesuai brand.

Tipografi — Hierarchy Kurang Kuat
Plus Jakarta Sans bagus, tapi hierarchy antar level terlalu dekat.
● Medium
Deck dan UI menggunakan banyak level ukuran teks (80px, 56px, 40px, 28px, 22px, 18px, 14px) tapi perbedaan bobot/kontras antar level kurang terasa. 05
Information Architecture — Sidebar Terlalu Padat
14 item navigasi flat tanpa grouping visual yang kuat menyebabkan cognitive overload.
● Medium
Sidebar saat ini memiliki 14 item navigasi dibagi dalam 6 grup dengan label uppercase. Masalah utamanya: semua grup terasa setara secara visual — tidak ada hirarki "primary vs secondary" yang jelas. Pengguna baru butuh waktu lama untuk menemukan fitur yang dibutuhkan.
⚡
Rekomendasi: Terapkan pola "Primary Nav + Secondary Collapse". Tampilkan 5–6 item utama selalu visible (Command Center, Projects, Cost, Schedule, Reports). Item lainnya masuk ke grup yang bisa di-collapse, atau pindah ke halaman Settings. Pertimbangkan juga tab bar bottom untuk mobile sebagai navigasi utama, bukan drawer.

07
Prioritas Perbaikan
Urutan implementasi yang disarankan berdasarkan impact vs effort.
🎨
1. Ganti palette — Dark Navy + Orange (1–2 hari)
Update colors_and_type.css: set dark default, hapus semua warna aksen per-nav-item, tetapkan orange sebagai primary brand. Dampak visual paling besar dengan effort rendah.
🧩
2. Redesign Sidebar — Monochrome icons, satu aksen (1 hari)
Hapus properti color dari data NAV di Sidebar.jsx. Gunakan satu --nav-active-color: var(--orange) untuk semua active state. Ikon tidak perlu warna — bentuk sudah cukup informatif.
📐
3. Kurangi item navigasi — Primary 5 item (1 hari)
Tampilkan Command Center, Projects, Cost, Schedule, dan Reports sebagai primary nav. Sisanya masuk ke sub-menu atau setting. Kurangi cognitive load pengguna baru.
✍️
4. Update typography — Ganti ke DM Sans, kurangi level (2 hari)
Ganti Plus Jakarta Sans ke DM Sans (lebih tegas, lebih konstruksi). Kurangi type scale dari 7 level ke 4: Display, Heading, Body, Label. Tambah letter-spacing negatif di heading.
✨
5. Tambah micro-interactions — Hover, focus, transitions (2–3 hari)
Setiap button butuh transform: scale(0.98) pada active. Card butuh border-color transition saat hover. Input butuh glow focus state. Tanpa ini, UI terasa "kaku" dan tidak responsif.
📊
6. Redesign KPI Cards — Angka lebih dominan, delta lebih jelas (2 hari)
KPI value harus menjadi elemen terbesar di card. Delta harus memiliki background pill berwarna (green/red) bukan hanya ikon kecil. Tambahkan sparkline mini untuk trend 7 hari.

Apa yang Harus Dibangun Selanjutnya?

Redesign design system dengan dark navy sebagai default, orange sebagai single brand accent, dan komponen yang lebih ekspresif. Ini bukan cosmetic fix — ini perubahan fundamental pada color philosophy dan component language.
