WBSDetailPanel — Spec

• Header: code badge (cobalt pill) + item name (Bricolage Grotesque font 16px)

Empty state: "Pilih item untuk melihat detail" with tree icon

📋 RAP — Rencana Anggaran Pelaksanaan
src/pages/modules/RAP.tsx
⏱ 8 jam · MARGIN ANALYSIS BUILD
⚠ File baru — perlu implement ✓ rapStore lengkap ✓ rapService + rapProfitService
Konsep RAP
RAP = perspektif biaya kontraktor (lebih rendah dari RAB). Selisih RAB-RAP = margin/profit proyek. KPI utama: "Margin Proyek: Rp X (Y%)". Setiap item RAP harus bisa diverifikasi vs item RAB equivalennya.
RAP.tsx ├── SummaryStrip │ ├── RAB Total (gold) — reference │ ├── RAP Total (cobalt) — execution cost │ ├── Margin Rp (jade if positive, coral if negative) │ ├── Margin % (jade/coral) │ └── Item Count ├── MarginHealthBar — horizontal bar showing RAB (full) vs RAP (portion) ├── Toolbar — [+Item] [Import dari RAB] [Export] [Lock/Unlock] └── RAP Table (same as RAB + Variance column) Variance: (rabPrice - rapPrice) / rabPrice * 100 Color: jade if positive margin, coral if negative
🔴
BUAT BARU: RAP module harus menampilkan perbandingan RAP vs RAB per item. Ini adalah core value proposition modul ini — tanpa ini, RAP tidak berguna.
🟡
Import dari RAB: Copy semua RAB items ke RAP dengan harga yang sama, biarkan user edit ke bawah. Ini adalah starting point yang wajar untuk estimasi biaya pelaksana.
🔵
Lock synchronization: Jika RAB dikunci, RAP juga harus terkunci (perubahan RAB setelah lock akan merusak perbandingan historis).
