PREAMBLE · Design System MERIDIAN v1.0 
DESIGN SYSTEM: MERIDIAN v1.0 — NATA LABA Construction Suite
Product: MLPHoma — Platform manajemen proyek konstruksi Indonesia (PWA, enterprise)
Target users: Project Manager, Quantity Surveyor, Site Manager, Finance, Direksi

=== TYPOGRAPHY ===
• Heading/Display: font "Bricolage Grotesque" — weight 700–800, letter-spacing -0.035em, opsz variable axis for large display
• Body/UI: font "Nunito Sans" — weight 400–700, readable and warm
• Numbers/Code/KPI: font "JetBrains Mono" — tabular figures (tnum), financial data only
• Table headers: uppercase, 10px, letter-spacing 0.12em, Nunito Sans 800

=== COLOR — DARK MODE (primary) ===
• Page background:    #060910  (obsidian black, near-void)
• Card surface:       #0C1220  (deep navy surface)
• Elevated panel:     #131C2E  (modals, drawers)
• Dropdown overlay:   #1A253C
• Border subtle:      #192338
• Border default:     #213047
• Text primary:       #E2EAF5  (contrast 15:1 — AAA)
• Text secondary:     #7A90AB  (contrast 6.1:1 — AA+)
• Text muted:         #3D5068  (placeholders only)
• Background grid texture: very faint blueprint lines at 80px major grid, 16px minor grid

=== COLOR — LIGHT MODE (warm limestone) ===
• Page background:    #F2EFE9  (warm limestone parchment)
• Card surface:       #FDFCF9  (warm white)
• Elevated:           #FFFFFF
• Border default:     #CEC8BA
• Text primary:       #1A1814  (warm near-black)
• Text secondary:     #50493E

=== ACCENT COLORS (both modes) ===
• Cobalt Blue (primary action, selection, links):
    Dark: #3B82F6 / #60A5FA    Light: #2563EB / #1E40AF
• Warm Gold (ALL IDR financial values — mandatory):
    Dark: #F59E0B / #FBBF24    Light: #D97706 / #92400E
• Jade Green (success, completed, positive CPI/SPI):
    Dark: #22C55E / #4ADE80    Light: #16A34A / #14532D
• Coral Red (danger, negative, error, rejection, overdue):
    Dark: #F43F5E / #FB7185    Light: #E11D48 / #9F1239
• Amber Orange (warning, pending, in-progress, SPI warn):
    Dark: #F97316 / #FB923C    Light: #EA580C / #9A3412
• Violet (analytics, AI, secondary insight):
    Dark: #8B5CF6 / #A78BFA    Light: #7C3AED / #5B21B6
• Teal (realtime, live data, auto-progress, online):
    Dark: #14B8A6 / #2DD4BF    Light: #0D9488 / #134E4A

=== STATUS PILLS ===
Compact rounded badges (border-radius full), 11px Nunito Sans 700, with a 5px circle dot prefix.
• ACTIVE / APPROVED / COMPLETED / PASSED → jade green
• PENDING / IN PROGRESS / SUBMITTED → amber orange
• OVERDUE / REJECTED / FAILED / ERROR → coral red
• PLANNING / INFO / LINKED → cobalt blue
• DRAFT / ARCHIVED / NEUTRAL → muted gray
• LIVE / REALTIME / AUTO → teal
• AI / ANALYTICS / SCENARIO → violet
• Budget/Financial context → warm gold

=== CARDS ===
• Background: surface color (dark: #0C1220, light: #FDFCF9)
• Border: 1px border-default
• Border radius: 12px
• Top accent strip: 3px colored border-top matching card category color
• Hover: slight translateY(-2px) + enhanced shadow
• Glow effect on KPI cards: 0 0 24px rgba(color, 0.16)

=== LAYOUT STRUCTURE (every page) ===
L1 — AppHeader (56px): Logo left | Active project + status center | Avatar/notif right
L2 — GlobalContextBar (44px): Project code | Name | Pipeline step | Status | Live indicator
L3 — WorkspaceHeader: Page title (Bricolage Grotesque font) + subtitle + action buttons right
L4 — SummaryStrip: Horizontal KPI cards (5-6 items), separated by 1px dividers
L5 — AlertStrip: Contextual warning banner (shown only when needed)
L6 — ContentArea: Main content (tree, table, chart, tabs)

=== NAVIGATION SIDEBAR (224px) ===
Dark: #0E1525 background, Groups: Overview, Cost Control, Schedule, Operations, Portfolio, System
Active item: cobalt blue highlight with left border accent
Icons: 16px Lucide icons, consistent

=== FINANCIAL DATA RULES ===
• ALL Rupiah (IDR) values MUST use JetBrains Mono font
• IDR values in dark mode: #FBBF24 (gold) color always
• IDR values in light mode: #92400E (dark amber) always
• Format: "Rp 12.800.000.000" (dot as thousands separator, no decimal for whole numbers)
• Percentage: "34,5%" (comma as decimal — Indonesian locale)
• Positive variance: jade green, Negative variance: coral red

=== WBS CODE BADGES ===
• L1 codes (1, 2, 3): cobalt blue pill background, JetBrains Mono bold
• L2 codes (1.1, 2.3): muted gray background, JetBrains Mono medium
• L3 codes (1.1.2): no background, muted text, JetBrains Mono

=== SHADOWS (dark mode) ===
• xs: 0 1px 2px rgba(0,0,0,0.5)
• sm: 0 2px 6px rgba(0,0,0,0.4)
• md: 0 4px 16px rgba(0,0,0,0.5)
• lg: 0 16px 40px rgba(0,0,0,0.6)

=== WCAG ACCESSIBILITY ===
• All text minimum 4.5:1 contrast ratio (AA)
• Financial data minimum 7:1 contrast ratio (AAA)
• Focus ring: 4px solid cobalt, 2px offset
• All interactive elements 44px minimum touch target

§ 7 — Tips Penggunaan
Tips Agar Hasil Stitch Optimal
💡 Struktur Prompt

Selalu mulai dengan PREAMBLE. Kemudian screen prompt. Stitch membaca secara urut — design system di awal = hasil lebih konsisten.

✅ Data Nyata

Gunakan data real: "Rp 12.800.000.000" bukan "IDR Value". "CMPLNG VILLAGE" bukan "Project Name". Data spesifik = hasil lebih realistis.

🔢 IDR Format

Selalu tulis: "Rp 12.800.000.000" (titik sebagai pemisah ribuan). Stitch akan merender angka ini dengan font JetBrains Mono + warna gold.

🎨 Iterasi

Jika hasil kurang akurat, screenshot hasilnya dan tempel sebagai referensi di prompt berikutnya: "Pertahankan layout ini, tapi ubah..."

📐 Ukuran Frame

Sebutkan ukuran frame di awal: "1440×900px desktop" atau "375×812px mobile". Stitch akan menyesuaikan density dan layout komponen.

⚠ Perhatikan

Stitch mungkin tidak merender font custom (Bricolage Grotesque/JetBrains). Anggap sebagai panduan style — implementasi aktual tetap di codebase.
